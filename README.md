
Projeto U-Easy (taxi-races)
Este projeto foi originalmente executado durante um processo seletivo para fazer parte da Liga de Engenharia de Dados (LED), um grupo de Projeto de Extensão na UFPE. 

Para esse projeto, foram utilizados os dados das viagens de taxi em Nova York durante Janeiro de 2024, e a pasta com o projeto inteiro executado com a equipe foi separada na pasta OLD. Todo conteúdo fora dessa pasta foi refeito e recapitulado por mim, para absorver o aprendizado que tive durante a execução da entrega desse projeto.

Pastas

Data - Arquivos brutos do banco de dados.
Docs - Dicionário dos dados registrados.
OLD - Arquivos originais da equipe executora.
src - Pasta com o projeto separado em Etapas.
